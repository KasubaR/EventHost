`php artisan icons:build-guest-css`) instead of loading the Font Awesome CDN stylesheet. See
plans/invitation-page-compatibility.md Phase 4. Attribution for the generated stylesheet is in its header comment.

To add an icon: download the SVG from the same version and folder, put it here, run the command, commit both.
